# **App Name**: Perfect Stitch

## Core Features:

- User Authentication: Enable secure user authentication via email/password or Google login.
- AI Measurement Extraction: Analyze uploaded full-body images to accurately extract body measurements, functioning as a tool for tailoring. The app supports Chest, Waist, Hip, Shoulder, Inseam, and Sleeve Length.
- Clothing Preferences Display: Display a curated list of preferred garment types (shirts, suits) with options for size, color, and style preferences.
- Garment Selection: Allow users to either buy or rent garments directly, displaying real-time fit previews.
- Order Tracking: Enable users to track their order history and current status with notifications via email.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5), evoking trust and sophistication, crucial for precise measurements.
- Background color: Light blue-gray (#F0F4F8), a soft, neutral backdrop that ensures focus on the clothing and measurements.
- Accent color: Lavender (#9575CD), adding a modern and tech-forward feel to the user interface.
- Font: 'Inter', a grotesque-style sans-serif that conveys modernity and neutrality, used for both headlines and body text.
- Use crisp, clear icons that visually represent each measurement and preference setting.
- Maintain a clean, structured layout to enhance clarity and precision in viewing body measurements and garment selections.
- Incorporate smooth transitions and loading animations to maintain user engagement during AI analysis.
